# Data Analytics Portfolio

Hi! I'm a Computer Science graduate building hands-on experience in data analytics. This portfolio showcases projects where I analyze data, create visualizations, and use data to answer business questions.

## Projects

### Deloitte Australia Data Analytics Job Simulation

**Tools:** Tableau, Microsoft Excel  
**Platform:** Forage

Analyzed manufacturing telemetry and employee compensation data to identify machine downtime patterns and classify pay equality data.

**Highlights:**
- Built an interactive Tableau dashboard to analyze downtime across factories and device types
- Used calculated fields to measure machine downtime
- Used Excel IF functions to classify employee pay equality scores
- Identified Daikibo Factory Seiko as the location with the highest machine downtime

### Online Shopping Orders Analysis

**Tools:** Google Sheets, SQL (SQLite)

Cleaned and analyzed a messy online shopping orders dataset to practice the full data analytics process from data cleaning to SQL analysis.

**Highlights:**
- Cleaned and standardized 320 order records in Google Sheets
- Removed duplicate rows and standardized categories, dates, states, payment methods, and order statuses
- Checked missing values and data types before analysis
- Used SQL to analyze sales by category and customer state
- Used SQL to identify top-selling products and analyze order statuses
- Documented data-quality decisions, including missing values and possible outliers
